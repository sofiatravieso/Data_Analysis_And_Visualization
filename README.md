# Análisis mundial de los gastos gubernamentales (2000 - 2021)

[Enlace al reporte interactivo](https://sofiatravieso.github.io/Data_Analysis_And_Visualization/Gastos_Gubernamentales.html)

## Descripción del Proyecto

Este repositorio contiene un análisis detallado de los gastos gubernamentales a nivel global durante el periodo comprendido entre los años 2000 y 2021. El documento explora la evolución de las finanzas públicas, permitiendo observar las tendencias macroeconómicas y los cambios en las políticas de inversión estatal a lo largo de más de dos décadas.

A nivel técnico, el reporte de resultados ha sido compilado mediante la herramienta Pandoc, resultando en un documento HTML independiente. Este archivo integra estilos CSS y scripts basados en jQuery (v3.6.0) para estructurar el texto, asegurar la correcta presentación de los datos y habilitar su compatibilidad con formatos de impresión.
